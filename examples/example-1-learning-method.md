# Example 1 — 描述一个学习方法

**Before**（原文，未修改）：

> While learning MRC yesterday， I found a new idea whic I think is very good way to learn sth new, especially for firmware development. In general, the idea to learn sth from 3 dimmsion (spec, code, and debug log) instead of only from code or spec, and then try to draw a gif picture to describle the flow. If I can use the metorpher gif to let the common people to understand it which means I've really known it.

**After**（日常口语版）：

> Yesterday I was studying MRC and **had a little lightbulb moment**. I realized that to really learn something new — especially firmware stuff — you should look at it **from three sides**: the spec, the code, and the debug log, not just the code or spec **by itself**. Then, try to **turn it into** a little GIF that shows how it works. If I can explain it to **a regular person** with that GIF, then I know **I've actually got it**.

**Key fixes**：

| 生硬 | 地道 |
|------|------|
| found a new idea | had a lightbulb moment |
| from 3 dimmsion | from three sides / angles |
| draw a gif picture | turn it into a GIF |
| let the common people understand | explain it to a regular person |
| I've really known it | I've actually got it |

**可迁移表达**：`have a lightbulb moment` · `boil down to` · `dig into` · `look at it from three angles` · `I've actually got it`
