**After**（日常口语版）：

> My place has a garage I can park in, which is super handy when it rains. But there's one thing that bugs me: I have to use the remote to open and close it, so I'm always carrying around a key just to open the door when I pull up. It's a pain. I've thought about fixing this before but never got anywhere. Now that I've got Claude and DeepSeek, I figured — can AI help me sort this out? After a few rounds back and forth, the AI gave me a proposal that I think might do the trick. I'm planning to get my hands on it soon. We'll see how it goes.

**Key fixes**：

| 生硬 | 地道 |
|------|------|
| gardge | garage |
| bugged me up at night | bugs me / keeps me up at night（两个表达别混）|
| turn it on/off（门）| open and close it |
| drive close to | pull up to / roll up to |
| without progress | never got anywhere |
| fix it up | sort it out / solve it |
| hand on it | get my hands on it / roll up my sleeves |

**可迁移表达**：`bug me` · `pull up to` · `sort it out` · `get my hands on it` · `go back and forth a few times` · `never get anywhere`
