# idiomatic-english-coach

> 把「正确但生硬」的英文，打磨成「地道自然」的英文。

一套 AI 口语教练工作流，帮你从"语法正确但生硬"进阶到"地道、自然、多样"，并附一套记忆系统，让学到的东西真正记得住、说得出口。

---

## 痛点

你能无障碍对话、听力也没问题、语法基本都对，但说出来的英文还是像"翻译腔"——**正确，却生硬**。你不满足于"能交流"，你想"说得好"。

## 核心理念：每天写一段「今天发生的小事」

- 生活里、工作中真实发生的一段小事——不用专门找话题，随手记录就行。
- 贴近真实场景，不是背课文，是你真经历过的事。
- **有趣、零负担、容易坚持**——这是能天天做下去的关键。

> 先写下来，再由 AI 帮你打磨、改写、提炼，最后开口说出来。

## 怎么用（3 步）

1. 把 [`coach-prompt.md`](coach-prompt.md) 的内容粘给任意 AI（Claude / ChatGPT 等）。
2. 用英文写一段今天发生的小事。**别先润色**——越"中式"、越原始，教练越能对症下药。
3. 看改写，大声读，然后把 Anki 卡导入，靠间隔重复记住。

## 核心闭环

```
写 → 分析改写 → 朗读 → 复述（Anki 间隔）
```

- **写**：建表达库
- **朗读**：练嘴，肌肉记忆
- **复述**：练脑，把"认得"变成"说得出"

## 能达到的效果

- 一句话被改写成三个版本（正式 / 日常 / 讲故事），表达**更多样、更生动**
- 每个话题学到 3~7 个**地道表达**，纠正中式直译和词义陷阱（比如 `slept late` ≠ 失眠）
- 通过 Anki 间隔重复 + 复述，把"我认得"升级成"我说得出口"
- 坚持 30 天，明显感到说话更顺、更自然、更有底气

## 真实案例

看 [`examples/`](examples/)，是真实中文母语工程师的英文 + 逐句纠错。

| # | 主题 | 亮点 |
|---|------|------|
| 1 | 学习方法 | `found a new idea` → `had a lightbulb moment` |
| 2 | UART 排障 | 乱码 → `garbled text`，折腾 → `mess around with`，皇天不负有心人 → `pay off` |
| 3 | 失眠 | `slept late` ≠ 失眠 → `couldn't sleep`，辗转反侧 → `toss and turn` |

## 适合谁

你英语已经能对话，但想让表达**更地道、更多样**；尤其是需要英文技术汇报、和同事用英文交流的工程师。

## English Summary

A spoken-English coaching workflow for Chinese speakers: write one short paragraph a day about something that really happened, let an AI (using `coach-prompt.md`) analyze it and rewrite it three ways, extract reusable patterns, then drill with Anki cards and story-retell cards so it actually sticks. The goal is to turn "correct but stiff" English into natural, idiomatic English.

See [`examples/`](examples/) for real before/after from a native-Chinese firmware engineer.
